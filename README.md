# Photon Correlation Analysis for X-rays (PhoeniX)

PhoeniX is an XPCS analysis package developed by the Universities of Siegen and Tübingen.

Version 0.1 (Work in Progress)
This is an early development version. The code is designed to be easily adapted through user-defined input and configuration, enabling its application to different synchrotron beamlines with minimal modifications.

Currently, PhoeniX supports the file structures used at P10 (DESY) and ID10 (ESRF). Additional beamlines can be supported by adapting the input configuration to the respective file structures and metadata.
